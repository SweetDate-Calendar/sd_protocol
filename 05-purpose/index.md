# Purpose

The goal of the SweetDate Protocol is to make it as easy as possible for developers to communicate with the SweetDate backend by providing a **natively supported DSL** (Domain-Specific Language).  

Instead of worrying about low-level API details, developers can focus on building user experiences, while SweetDate takes care of the complex scheduling logic.
